# Chekila.github.io
# Personal Website

This repository contains the source code for my personal website, 
available at **https://chekila.github.io/**.

The site is built with R Markdown and hosted on GitHub Pages. It was 
created as part of Homework 4 for P8105 Data Science I at Columbia University.

## Site contents

* **Home** (`index.Rmd`): a brief introduction
* **Resume** (`resume.Rmd`): education, research, and work experience
* **Dashboard** (`dashboard.Rmd`): an interactive dashboard built with 
  `plotly` and `flexdashboard`

## Repository structure

* `_site.yml`: site-wide settings, including the navigation bar and theme
* `*.Rmd`: source files for each page
* `*.html` and `site_libs/`: rendered website files, generated by 
  `rmarkdown::render_site()`

## How to build

Open `Chekila.github.io.Rproj` in RStudio and click **Build → Build Website**.
